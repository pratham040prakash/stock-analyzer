## Summary

APEX V2 delivers a unified daily decision experience: a **Home Command Center** for Today, a structured **Review Workspace** for execution review, shared visual polish, performance and accessibility hardening, and release-candidate hardening with a single Review Depth compositor.

This RC preserves all V1 presentation contracts (APS-001–006) with no analyzer or business-logic changes.

## Highlights

- **Verdict-first Today surface** — Hero, action row, status strip, progressive disclosure
- **Review Workspace hierarchy** — Hero → Execution Plan → Review Depth
- **Single Review Depth compositor** — `decision_depth_panel` shared by Today popover and Review page
- **Shared theme system** — `APEX_PARTNER_EXPERIENCE_CSS` pre-built bundle
- **Accessibility basics** — Semantic landmarks, ARIA labels, focus-visible rings, reduced-motion support
- **Render performance** — CSS consolidation, `content-visibility` on below-fold sections

## Known Limitations

- Legacy Phase 1 CSS remains bundled for dock/overlay compatibility
